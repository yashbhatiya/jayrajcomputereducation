Module 1 — Introduction to Node.js

What is Node.js?

Node.js is a JavaScript runtime built on Chrome's V8 engine that allows you to run JavaScript outside the browser — on your server, computer, or any machine. It uses a single-threaded, non-blocking, event-driven model which makes it extremely efficient for I/O-heavy operations like web servers, APIs, and file handling. Node.js is not a language — it's an environment that executes JavaScript. Companies like Netflix, LinkedIn, Uber, and PayPal use Node.js in production because it handles thousands of concurrent connections with minimal resources.
Real-World Use Cases
REST APIs · Real-time chat apps (Socket.io) · Streaming services (Netflix) · CLI tools · Microservices · BFF (Backend for Frontend) layers · Serverless functions

Module 1 — Introduction to Node.js

Node.js Architecture

Node.js is built on the V8 JavaScript engine (same one in Chrome) plus libuv — a C library that provides the event loop, thread pool, and async I/O. The architecture is single-threaded for JavaScript execution but uses multiple OS threads for I/O operations under the hood. When an async operation completes (file read, network response), a callback is placed on the event queue and the event loop picks it up when the call stack is empty. This makes Node.js perfect for I/O-bound workloads but not ideal for CPU-intensive tasks like video encoding.

Module 2 — Runtime Concepts

Event Loop Deep Dive

The event loop is Node.js's secret weapon. It's a loop that constantly checks: "Is the call stack empty? Are there callbacks waiting in the queue?" The loop has specific phases: timers → pending callbacks → idle → poll → check → close callbacks. Understanding phase order is critical for predicting execution order in async code. The microtask queue (Promises, process.nextTick) runs between every phase — these have higher priority than any timer or I/O callback.

Module 2 — Runtime Concepts

Timers: setTimeout, setInterval, setImmediate

Node.js provides three timer functions: setTimeout fires a callback once after a delay; setInterval fires repeatedly at a fixed interval; setImmediate fires at the end of the current event loop iteration (before I/O callbacks). All three are non-blocking — the thread continues executing while the timer is pending. Use clearTimeout(), clearInterval(), and clearImmediate() to cancel them. In production, setInterval is used for health checks, cache refreshes, and scheduled jobs.
PROGRAM 1 Rate Limiter Using setInterval

// rate-limiter.js — Token bucket rate limiter

class RateLimiter {
  constructor(maxRequests, windowMs) {
    this.tokens = maxRequests;
    this.maxTokens = maxRequests;

    // Refill tokens at regular intervals
    this.refillTimer = setInterval(() => {
      this.tokens = this.maxTokens;
      console.log(`\n🔄 Tokens refilled to ${this.maxTokens}`);
    }, windowMs);

    // Prevent timer from blocking process exit
    this.refillTimer.unref();
  }

  consume(requestId) {
    if (this.tokens > 0) {
      this.tokens--;
      console.log(`✅ Request ${requestId} allowed. Tokens left: ${this.tokens}`);
      return true;
    }
    console.log(`❌ Request ${requestId} BLOCKED — rate limit exceeded`);
    return false;
  }

  destroy() {
    clearInterval(this.refillTimer);
  }
}

  limiter.consume(reqId++);

// scheduler.js — Simple scheduled task runner

class Scheduler {
  constructor() {
    this.jobs = new Map();
  }

  // Schedule a job to run every `intervalMs` milliseconds
  every(name, intervalMs, task) {
    if (this.jobs.has(name)) {
      throw new Error(`Job '${name}' already exists`);
    }

    const timer = setInterval(async () => {
      const start = Date.now();
      try {
        await task();
        console.log(`[${new Date().toLocaleTimeString()}] ✅ ${name} ran in ${Date.now() - start}ms`);
      } catch (err) {
        console.error(`[${new Date().toLocaleTimeString()}] ❌ ${name} failed: ${err.message}`);
      }
    }, intervalMs);

    this.jobs.set(name, timer);
    console.log(`📅 Scheduled: '${name}' every ${intervalMs / 1000}s`);
  }

  cancel(name) {
    const timer = this.jobs.get(name);
    if (timer) {
      clearInterval(timer);
      this.jobs.delete(name);
      console.log(`🛑 Cancelled: '${name}'`);
    }
  }

function sendJSON(res, statusCode, data) {
  res.writeHead(statusCode, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(data, null, 2));
}

// Helper: read request body
function readBody(req) {
  return new Promise((resolve, reject) => {
    let body = '';
    req.on('data', chunk => (body += chunk));
    req.on('end',  () => {
      try { resolve(JSON.parse(body || '{}')); }
      catch (e) { reject(new Error('Invalid JSON body')); }
    });
    req.on('error', reject);
  });
}

const server = http.createServer(async (req, res) => {
  const { method, url } = req;

  // Log every request
  console.log(`[${new Date().toISOString()}] ${method} ${url}`);

  try {
    // Route: GET /
    if (method === 'GET' && url === '/') {
      return sendJSON(res, 200, { message: 'Users API v1.0', endpoints: ['/users', '/users/:id'] });
    }

    // Route: GET /users
    if (method === 'GET' && url === '/users') {
      return sendJSON(res, 200, { success: true, data: users });
    }

    // Route: GET /users/:id
    const userMatch = url.match(/^\/users\/(\d+)$/);
    if (method === 'GET' && userMatch) {
      const user = users.find(u => u.id === parseInt(userMatch[1]));
      if (!user) return sendJSON(res, 404, { error: 'User not found' });
      return sendJSON(res, 200, { success: true, data: user });
    }

    // Route: POST /users
    if (method === 'POST' && url === '/users') {
      const body = await readBody(req);
      if (!body.name) return sendJSON(res, 400, { error: 'Name is required' });

      users.push(newUser);
      return sendJSON(res, 201, { success: true, data: newUser });
    }

    // 404 — no route matched
    sendJSON(res, 404, { error: `Cannot ${method} ${url}` });

  } catch (err) {
    sendJSON(res, 500, { error: err.message });
  }

Node.js uses CommonJS as its default module system. Every file is its own module with its own scope — variables defined in one file don't leak into another. // Helper: send JSON response
function sendJSON(res, statusCode, data) {
  res.writeHead(statusCode, { 'Content-Type': 'application/json' });
  res.end(JSON.stringify(data, null, 2));
}

// Helper: read request body
function readBody(req) {
  return new Promise((resolve, reject) => {
    let body = '';
    req.on('data', chunk => (body += chunk));
    req.on('end', () => {
      try { resolve(JSON.parse(body || '{}')); }
      catch (e) { reject(new Error('Invalid JSON body')); }
    });
    req.on('error', reject);
  });
}

const server = http.createServer(async (req, res) => {
  const parsed   = url.parse(req.url, true);
  const pathname = parsed.pathname;
  const method   = req.method;

  console.log(`${method} ${pathname}`);

  try {
    // GET /
    if (pathname === '/' && method === 'GET') {
      return sendJSON(res, 200, { message: 'Welcome to the API', version: '1.0.0' });
    }

    // GET /users
    if (pathname === '/users' && method === 'GET') {
      return sendJSON(res, 200, { count: users.length, data: users });
    }

    // GET /users/:id  (e.g. /users/2)
    const userMatch = pathname.match(/^\/users\/(\d+)$/);
    if (userMatch && method === 'GET') {
      const user = users.find(u => u.id === parseInt(userMatch[1]));
      if (!user) return sendJSON(res, 404, { error: 'User not found' });
      return sendJSON(res, 200, user);
    }

    // POST /users
    if (pathname === '/users' && method === 'POST') {
      const body = await readBody(req);
      if (!body.name || !body.email) {
        return sendJSON(res, 400, { error: 'name and email are required' });
      }
      const newUser = { id: users.length + 1, ...body };
      users.push(newUser);
      return sendJSON(res, 201, newUser);
    }

    // 404 — route not found
    sendJSON(res, 404, { error: `Route ${method} ${pathname} not found` });

  } catch (err) {
    sendJSON(res, 500, { error: 'Internal Server Error', details: err.message });
  }
});

  '.html': 'text/html',
  '.css':  'text/css',
  '.js':   'application/javascript',
  '.json': 'application/json',
  '.png':  'image/png',
  '.jpg':  'image/jpeg',
  '.svg':  'image/svg+xml',
  '.ico':  'image/x-icon'
};

const PUBLIC_DIR = path.join(__dirname, 'public');

const server = http.createServer((req, res) => {
  // Sanitise path — prevent directory traversal attacks
  let filePath = path.join(PUBLIC_DIR, req.url === '/' ? 'index.html' : req.url);

  // Security: ensure resolved path is inside PUBLIC_DIR
  if (!filePath.startsWith(PUBLIC_DIR)) {
    res.writeHead(403);
    return res.end('Forbidden');
  }

  const ext         = path.extname(filePath);
  const contentType = MIME_TYPES[ext] || 'application/octet-stream';

  // Use stream for efficiency — no loading file into memory
  const stream = fs.createReadStream(filePath);

  stream.on('error', (err) => {
    if (err.code === 'ENOENT') {
      res.writeHead(404);
      res.end('404 — File Not Found');
    } else {
      res.writeHead(500);
      res.end('Internal Server Error');
    }
  });

  stream.on('ready', () => {
    res.writeHead(200, {
      'Content-Type':  contentType,
      'Cache-Control': 'public, max-age=3600'
    });
    stream.pipe(res);  // pipe stream directly to response
  });

  console.log(`[${new Date().toISOString()}] GET ${req.url}`);
});

Module 7 — Routing System

Route Parameters

Route parameters are named URL segments prefixed with :. When a request hits /users/42 and your route is /users/:id, Express extracts 42 and puts it in req.params.id. You can have multiple params: /users/:userId/orders/:orderId. Parameters are always strings — always parse numbers with parseInt() or Number(). You can also add regex constraints: /users/:id(\\d+) only matches numeric IDs. Route params are fundamental to RESTful API design.

Module 8 — Middleware

What is Middleware?

Middleware are functions that sit between the incoming request and the final route handler. Each middleware receives (req, res, next). It can read/modify the request, send a response early (short-circuit), or call next() to pass control to the next middleware. Think of it as a pipeline — every request flows through layers of middleware before reaching the route. Built-in middleware includes express.json() and express.static(). Third-party examples: cors, helmet, morgan. Custom middleware is where you add logging, authentication, input validation, and rate limiting.

Request → [Logger] → [CORS] → [Auth Check] → [Body Parser] → [Rate Limiter] → [Route Handler] → Response

class AppError extends Error {
  constructor(message, statusCode, code) {
    super(message);
    this.statusCode   = statusCode;
    this.code         = code || 'APP_ERROR';
    this.isOperational = true;  // Distinguishes from programmer errors

const asyncHandler = (fn) => (req, res, next) => {
  Promise.resolve(fn(req, res, next)).catch(next);
};

// Central error handler — MUST have 4 parameters
const errorHandler = (err, req, res, next) => {
  const isDev = process.env.NODE_ENV !== 'production';

  // Log the full error server-side
  console.error(`[ERROR] ${req.method} ${req.path}:`, err.message);

  const statusCode = err.statusCode || 500;

  res.status(statusCode).json({
    success:   false,
    error:     err.code || 'INTERNAL_ERROR',
    message:   err.isOperational ? err.message : 'Something went wrong',
    // Only expose stack trace in development!
    ...(isDev && { stack: err.stack })
  });
};

Response Methods (res)

The response object (res) is used to build and send the HTTP response back to the client. Key methods: res.json(data) sends JSON with correct Content-Type; res.send(body) sends a string, Buffer, or object; res.status(code) sets the HTTP status code (chainable); res.redirect(url) sends a 302 redirect; res.sendFile(path) streams a file; res.set(header, value) sets response headers; res.cookie(name, value, options) sets a cookie. // Attach to res object via middleware so all routes can use them

const responseMiddleware = (req, res, next) => {

  // Success response
  res.success = (data, message = 'Success', statusCode = 200) => {
    return res.status(statusCode).json({
      success:   true,
      message,
      data,
      timestamp: new Date().toISOString()
    });
  };

  // Created (201)
  res.created = (data, message = 'Resource created') =>
    res.success(data, message, 201);

  // Paginated list
  res.paginated = (data, { page, limit, total }) => {
    return res.status(200).json({
      success: true,
      data,
      pagination: {
        page:       Number(page),
        limit:      Number(limit),
        total,
        totalPages: Math.ceil(total / limit),
        hasNext:    page * limit < total,
        hasPrev:    page > 1
      }
    });
  };

  // Error responses
  res.badRequest   = (message, errors)  => res.status(400).json({ success: false, error: 'BAD_REQUEST',   message, errors });
  res.unauthorized = (message)           => res.status(401).json({ success: false, error: 'UNAUTHORIZED', message });
  res.forbidden    = (message)           => res.status(403).json({ success: false, error: 'FORBIDDEN',     message });
  res.notFound     = (resource)         => res.status(404).json({ success: false, error: 'NOT_FOUND',     message: `${resource} not found` });

  next();
};

// Lightweight JSON file store — simulates a database
const fs   = require('fs');
const path = require('path');

function createStore(filename) {
  const filePath = path.join(__dirname, '../../data', filename);

  // Initialize file with empty array if not exists
  if (!fs.existsSync(filePath)) fs.writeFileSync(filePath, '[]');

  return {
    read() {
      return JSON.parse(fs.readFileSync(filePath, 'utf8'));
    },
    write(data) {
      fs.writeFileSync(filePath, JSON.stringify(data, null, 2));
    },
    findById(id) {
      return this.read().find(item => item.id === id);
    },
    insert(item) {
      const data = this.read();
      data.push(item);
      this.write(data);
      return item;
    },
    updateById(id, updates) {
      const data = this.read();
      const idx  = data.findIndex(i => i.id === id);
      if (idx === -1) return null;
      data[idx] = { ...data[idx], ...updates, updatedAt: new Date().toISOString() };
      this.write(data);
      return data[idx];
    },
    deleteById(id) {
      const data    = this.read();
      const filtered = data.filter(i => i.id !== id);
      const deleted  = data.length !== filtered.length;
      if (deleted) this.write(filtered);
      return deleted;
    }
  };
}

const bcrypt  = require('bcryptjs');
const jwt     = require('jsonwebtoken');
const { v4: uuidv4 } = require('uuid');
const store   = require('../utils/store');

const makeError = (msg, code) => {
  const e = new Error(msg);
  e.statusCode = code;
  return e;
};

const authService = {
  async register({ name, email, password }) {
    if (!name || !email || !password)
      throw makeError('name, email, and password are required', 400);
    if (password.length < 6)
      throw makeError('Password must be at least 6 characters', 400);

    const exists = store.users.read().find(u => u.email === email);
    if (exists) throw makeError('Email already registered', 409);

    const hashedPassword = await bcrypt.hash(password, 12);
    const user = {
      id:        uuidv4(),
      name, email,
      password:  hashedPassword,
      role:      'user',
      createdAt: new Date().toISOString()
    };
    store.users.insert(user);
    const { password: _, ...safeUser } = user;  // Never return password!
    return safeUser;
  },

  async login({ email, password }) {
    if (!email || !password)
      throw makeError('Email and password are required', 400);

    const user = store.users.read().find(u => u.email === email);
    if (!user) throw makeError('Invalid credentials', 401);

    const valid = await bcrypt.compare(password, user.password);
    if (!valid) throw makeError('Invalid credentials', 401);

    const token = jwt.sign(
      { id: user.id, email: user.email, role: user.role },
      process.env.JWT_SECRET,
      { expiresIn: process.env.JWT_EXPIRES_IN }
    );
    const { password: _, ...safeUser } = user;
    return { token, user: safeUser };
  }
};

const { v4: uuidv4 } = require('uuid');
const store          = require('../utils/store');

const VALID_STATUS   = ['todo', 'in-progress', 'done'];
const VALID_PRIORITY = ['low', 'medium', 'high', 'critical'];

const makeError = (msg, code) => { const e = new Error(msg); e.statusCode = code; return e; };

const taskService = {
  async getAll(userId, { status, priority, projectId, q, page = 1, limit = 10 } = {}) {
    let tasks = store.tasks.read().filter(t => t.userId === userId);
    if (status)    tasks = tasks.filter(t => t.status === status);
    if (priority)  tasks = tasks.filter(t => t.priority === priority);
    if (projectId) tasks = tasks.filter(t => t.projectId === projectId);
    if (q)          tasks = tasks.filter(t =>
      t.title.toLowerCase().includes(q.toLowerCase())
    );
    const total = tasks.length;
    const data  = tasks.slice((page-1)*limit, page*limit);
    return { data, total, page: Number(page), limit: Number(limit), totalPages: Math.ceil(total/limit) };
  },

  async create(userId, { title, description, priority, dueDate, projectId }) {
    if (!title)                           throw makeError('Task title is required', 400);
    if (priority && !VALID_PRIORITY.includes(priority))
      throw makeError(`Priority must be: ${VALID_PRIORITY.join(', ')}`, 400);

    const task = {
      id:          uuidv4(),
      userId, title, description, projectId,
      status:      'todo',
      priority:    priority || 'medium',
      dueDate:     dueDate || null,
      attachments: [],
      createdAt:   new Date().toISOString(),
      updatedAt:   new Date().toISOString()
    };
    return store.tasks.insert(task);
  },

  async updateStatus(userId, taskId, status) {
    if (!VALID_STATUS.includes(status))
      throw makeError(`Status must be: ${VALID_STATUS.join(', ')}`, 400);
    const task = store.tasks.findById(taskId);
    if (!task || task.userId !== userId)
      throw makeError('Task not found', 404);
    return store.tasks.updateById(taskId, { status });
  },

  async getStats(userId) {
    const tasks    = store.tasks.read().filter(t => t.userId === userId);
    const today   = new Date().toISOString().split('T')[0];
    return {
      total:      tasks.length,
      todo:       tasks.filter(t => t.status === 'todo').length,
      inProgress: tasks.filter(t => t.status === 'in-progress').length,
      done:       tasks.filter(t => t.status === 'done').length,
      overdue:    tasks.filter(t => t.dueDate && t.dueDate < today && t.status !== 'done').length,
      byPriority: VALID_PRIORITY.reduce((acc, p) => (
        { ...acc, [p]: tasks.filter(t => t.priority === p).length }
      ), {})
    };
  }
};

Module 2 — Runtime Concepts

Blocking vs Non-Blocking Code

Blocking code halts the entire thread until an operation completes — no other code runs during that wait. Non-blocking code starts an operation and immediately moves on; a callback/Promise handles the result when it's ready. In a web server, blocking one request blocks ALL requests from all users. Non-blocking I/O is why Node.js can serve thousands of concurrent users with a single thread. The golden rule: never use *Sync methods in a running server — they block the event loop.
Reference — When to use Sync vs Async
Use Sync only at startup (reading config before server starts). Use async everywhere else.

Module 8 — Middleware

Error-Handling Middleware

Error-handling middleware has exactly 4 parameters: (err, req, res, next). Express automatically detects this signature. Register it as the last app.use() call. To pass an error to it, call next(err) from any route or middleware. For async routes, errors thrown inside async functions won't reach the error handler unless you wrap them with a try/catch and call next(err). The asyncHandler utility wrapper from Topic 8.1 Program 3 solves this cleanly.
Module 10 — Application Structure

Controllers & Services

Controllers are thin HTTP adapters: they extract data from req, call services, and format responses. They should have minimal logic. Services contain all business logic — calculations, validations, data transformations, calling external APIs. Services must never use req/res — they work with plain JavaScript values, making them fully testable without HTTP. This separation is what makes large codebases maintainable. A good rule: if your controller is more than 15 lines, move logic to a service. See Topic 10.1 for complete MVC implementation.
